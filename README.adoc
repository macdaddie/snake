= snake

A Bash and Zsh function for renaming files and directories to `snake_case`.

The `snake` function normalizes case, spaces, punctuation, periods, and brackets. It can process a single path, the current directory, or a directory tree, and it can either avoid collisions with `_N` suffixes or overwrite existing targets.

== Installation

The function is defined in `snake_func.sh`. Source that file from your shell configuration.

=== Bash

Add the following line to `~/.bashrc`, replacing the path with the location of your checkout:

[source,bash]
----
source "/path/to/snake/snake_func.sh"
----

=== Zsh

Add the following line to `~/.zshrc`, replacing the path with the location of your checkout:

[source,bash]
----
source "/path/to/snake/snake_func.sh"
----

=== Automatic setup

To detect the shell and add a source line automatically, set `snake_func` to the absolute path of `snake_func.sh`, then run:

[source,bash]
----
snake_func="$HOME/.local/share/snake/snake_func.sh"
rc=$([[ $SHELL == */zsh ]] && echo "${ZDOTDIR:-$HOME}/.zshrc" || echo "$HOME/.bashrc")
line="source \"$snake_func\""
grep -Fqx "$line" "$rc" 2>/dev/null || printf '\n%s\n' "$line" >> "$rc"
----

== Quick start

[source,bash]
----
source "/path/to/snake/snake_func.sh"

snake "My File.txt"          # my_file.txt
snake -r .                   # process the current directory recursively
snake -o "My File.txt"       # overwrite an existing my_file.txt
----

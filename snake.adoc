= snake_func.sh Manual

== Introduction

The `snake_func.sh` script is designed to rename files and directories by converting their names to a "snake_case" format. This involves replacing spaces and special characters with underscores, ensuring filenames are consistent and easy to handle in various systems.

== Usage

*Command Syntax*::
`snake [-r|--recursive] [-p|--period] <path>`

*Options*::
* `-h, --help`: Display help information
* `-r, --recursive`: Process directories recursively
* `-p, --period`: Preserve periods in names (don't replace with underscores)

*Arguments*::
* `<path>`: The path to a file or directory to be renamed

*Behavior*::
* When the target filename already exists, appends `_N` suffix where N is an incrementing number
  (e.g., `file_1.txt`, `file_2.txt`, etc.) to prevent overwriting
* Skips renaming if the transformed name matches the original filename exactly
* When preserving periods (`-p`), the counter is still appended as an underscore-separated number

*Examples*::
* Rename a single file to snake_case (default, periods become underscores):
  `snake this.is/my.file.txt` → `this_is_my_file.txt`
* Rename with periods preserved:
  `snake -p this.is/my.file.txt` → `this.is.my.file.txt`
* Rename files in a directory (non-recursive, default):
  `snake /path/to/directory`
* Rename files in a directory (recursive):
  `snake -r /path/to/directory`

=== Period Handling

By default, periods are replaced with underscores in both files and directories (except for the period separating the filename from its extension).

*Default (without -p)*::
  - Multiple consecutive periods are collapsed to a single underscore
  - `subject.status.date/` → `subject_status_date/`
  - `this...is.my.file.txt` → `this_is_my_file.txt`

*With -p/--period*::
  - Periods are preserved as separators between words
  - Multiple consecutive periods are collapsed to a single period
  - `subject.status.date/` → `subject.status.date/`
  - `this...is.my.file.txt` → `this.is.my.file.txt`

=== Recursive Behavior

By default, the `snake` function processes only the specified file or the immediate contents of a directory. To process directories recursively (including all subdirectories), use the `-r` or `--recursive` flag.

Without `-r`, if a directory is provided, only files and directories directly in that path are processed. With `-r`, the function iterates through all subdirectories and renames files at every level.

== Design and Flow

The script follows a structured approach to ensure filenames are converted to snake_case:

* *snake_transform Function*:
  - A reusable function that applies all transformations to convert text to snake_case.
  - The function accepts an optional second parameter to control period handling.
  - **Transformation order is critical** - each step depends on the previous one to produce correct results:
    1. **Convert to lowercase** - ensures consistent casing before any other transformations
    2. **Replace spaces with underscores** - converts word separators first, before collapsing
    3. **Replace periods with underscores** - when NOT preserving periods (flag=0)
    4. **Replace other special characters with underscores** - commas, exclamation marks, pipes, middle dots
    5. **Remove apostrophes** - removes contractions and quotes
    6. **Collapse multiple underscores** - reduces `____` to `_` (this must happen BEFORE removing trailing chars)
    7. **When preserving periods (flag=1)**: the function replaces periods with underscores first, collapses underscores, then converts back to periods
    8. **Remove trailing non-alphanumeric characters** - final cleanup of dangling separators
  
  \n\n*Important note about order*:
  - Underscore/hyphen collapsing must happen BEFORE trailing character removal, otherwise `____` would collapse to `_` but then the trailing removal would strip it
  - Period replacement must happen BEFORE underscore collapsing when `replace_periods=0`, or you'd have `____` instead of `___` after collapsing
  - When preserving periods with `-p`, the approach is: replace periods with underscores → collapse underscores → convert underscores back to periods

* *Filename Processing*:
  - Extracts the directory path, filename, and extension.
  - For the extension: always replaces periods (the extension itself can't contain meaningful periods).
  - For the base name:
    - Without `-p`: replaces periods with underscores
    - With `-p`: preserves periods in the base name (using placeholder approach)
  - Reconstructs the filename with the new base and extension.

* *Directory Processing*:
  - Without `-p`: periods are replaced with underscores
  - With `-p`: periods are preserved
  - If `-r` flag is set, iterates over all entries recursively.

* *Period Flag Behavior*:
  - The `-p` flag applies to both files and directories uniformly.
  - The period between filename and extension is always preserved (not replaced).

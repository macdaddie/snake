= snake_func.sh Manual

== Introduction

The `snake_func.sh` script is designed to rename files in a directory by converting their filenames to a "snake_case" format. This involves replacing spaces and special characters with underscores, ensuring filenames are consistent and easy to handle in various systems.

== Usage

*Command Syntax*::
`snake <directory_or_file_path>`

*Parameters*::
* `directory_or_file_path`: The path to a directory or file to be processed. If a directory is provided, all files within it will be processed.

*Examples*::
* Rename all files in a directory to snake_case:
  `snake /path/to/directory`
* Rename a single file to snake_case:
  `snake /path/to/file.txt`

== Design and Flow

The script follows a structured approach to ensure filenames are converted to snake_case:

* *Directory Check*:
  - If the provided path is a directory, the script iterates over each file and calls itself recursively.

* *Filename Processing*:
  - Extracts the directory path, filename, and extension.
  - Trims leading and trailing spaces from the filename.
  - Replaces spaces, periods, commas, pipes, and other special characters with underscores.
  - Removes any double underscores or hyphens.
  - Constructs the new filename and moves the file to the new name.

* *Loop Logic*:
  - The script processes each file in the directory recursively, ensuring all filenames are converted.
